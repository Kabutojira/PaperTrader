## Recreate the read-only census

```bash
uv run python -m papertrader.migration_inventory \
  --revision pre-research-only-20261018 --as-of 2026-10-18
uv run python -m papertrader.migration_inventory \
  --revision pre-research-only-20261018 --as-of 2026-10-18 \
  --output /tmp/papertrader-pre-research-only-20261018.json
```

Without `--output`, the command only prints a summary. An explicit export must be
outside the repository. It reads committed data through `git archive`, never the
working-tree data. The export includes every data file's size/SHA-256, every CSV's
columns and row count, security/issuer identities, current research rows, wiki
references and the original active queue census. The compact committed summary is
[m0-baseline.json](m0-baseline.json); the full census can always be regenerated
from the tag rather than kept as another active history directory. The census and
