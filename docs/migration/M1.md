# M1: compact current-research schema and migration

`schemas/research_contracts.yaml` defines six research-only CSV contracts:
securities, ideas, relationships, current assessments, current sources and the
bounded entity queue. `papertrader.research_state` validates exact headers and
keys, source references, stable endpoints, safe entity pages and links, UTC dates,
native currencies and ordered decimal scenarios with probabilities totaling 100.
There are no portfolio actions, allocation gates, revision IDs or histories in
these contracts. Distinct instruments may share an issuer without being merged.

Run a no-write migration against a pinned commit:

```bash
uv run python -m papertrader.research_migration \
  --revision 9056d3dff03740a6c3310e086a240186bca4527a
```

For a reviewable isolated output, explicitly supply a destination:

```bash
uv run python -m papertrader.research_migration \
  --revision 9056d3dff03740a6c3310e086a240186bca4527a \
  --stage /tmp/papertrader-research-m1-stage
```

The default does not write. Staging validates in memory before creating the
output, rejects the active data directory, and atomically renames a new directory
into place. Repeating the identical stage is a no-op, including modification
times; a different existing output is rejected. It never copies financial
ledgers, run snapshots or the old operation queue into the new tables. The old
wiki is initially retained for reference-aware pruning in M8, not as a new
research-history authority.

The inspected migration produces 92 securities, 29 ideas, 47 relationships, 83
current assessments and 366 sources. It preserves all security/issuer/venue/
provider/currency identities, scenario values/probabilities/assumptions and exact
research/expiry timestamps. Of the 83 assessments, 71 contain supported historical
scenarios and 12 remain unsupported. As of October 18, 82 assessments are expired
and there are zero current supported valuations. No timestamp or fair value is
manufactured. The queue is initially empty; M3 reconstructs bounded current demand
rather than replaying old requests or dependencies.

Idea dates come from existing quoted frontmatter dates; absent dates remain
empty. Source IDs remain stable and publication timestamps stay empty when
unknown: a retrieval date is not a publication date. Existing valuation-method
rationale is retained, falling back only to actual valuation prose already in
the page. Current research prose, assets and citations are preserved; two inline
legacy assessment IDs on one page become explicit pre-migration Git links.

The active legacy reader and frozen data remain intact while these new contracts
are staged. M4 owns the validated current-state transaction and reader switch;
M7 owns scheduled runtime cutover. This prevents an intermediate schema change
from reviving or corrupting the old scheduler. M8 removes old contracts and data
once all consumers have migrated. No new compatibility mode is a final product
feature.

Local validation passed: ten focused migration/inventory tests and all 626 tests,
Ruff check/format, MyPy across 64 source files, and strict schema/integrity/wiki/
advice/reconciliation gates. This is staged migration verification, not a live
research refresh or deployment. Exact commits and CI runs are tracked in PLAN.md.
