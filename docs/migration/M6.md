# M6: current research publication

`papertrader publish` previews current deterministic rankings; `--apply` writes
only generated Markdown and small Buy/Sell CSV and rankings JSON downloads.
The underlying research dates and fair values remain unchanged. No LLM is used.

Rankings require complete supported scenarios, medium/high confidence, an in-date
assessment, currently valid sources checked during research and the latest
completed exchange-session quote matching canonical listing identity/currency.
Subsequent splits require actual research. Missing analytical charts are harmless.
Explicit `BLOCKER:` limitations force Unrated; unresolved material evidence must
otherwise be represented by an unsupported research outcome.

The methodology page documents thresholds, expected-return calculation and
confidence shrinkage. Lists contain zero through ten distinct issuers, ordered by
adjusted prospective return with immutable identity tie-breaks. Stale research is
browseable through the company catalog but cannot enter current rankings.

The pinned Quartz build stages a bounded closure of current company/idea pages
and linked source/research assets outside the repository, generates current views
from validated tables and copies only research downloads. Retired trading pages
are excluded; existing references to them point to the verified backup Git ref.
No source prose or current citation is removed from canonical storage by staging.
The old seeded trading fixture no longer owns public-site assertions; current
publication tests and the actual Quartz build check the new product.

M6 does not activate scheduling. The daily13:00 America/New_York schedule is
activated by M7's independent research-only workflows. No historical valuation is
made current to populate the homepage.
