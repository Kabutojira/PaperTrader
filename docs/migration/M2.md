# M2: standalone market and valuation core

`research_market.py` and `research_ratings.py` import no portfolio, allocation,
order, advice, FX or historical-research code. They consume native-currency
security identity, ordinary price caches and current assessments. They remain
standalone while M4/M7 migrate the active reader and scheduled entry points.

Version-controlled defaults are in `research.ini`: batches of eight symbols,
24 provider calls, 320 underlying HTTP requests, 15-second HTTP timeouts, at most
two attempts, ten-minute runtime, a 365-day price cache and weekly seven-day
correction windows. A cold refresh of the current 92-security universe can require
one chart request and one currency-metadata request per symbol, plus shared Yahoo
session setup and bounded failed-symbol retries; the 320-request ceiling covers
that path without becoming unbounded. The yfinance adapter uses sequential
retrieval and one session that checks the HTTP/time budget before each request.
Only failed symbols get individual backoff retries. A cache-current repeat calls
neither price nor metadata endpoints. No quote or feature requests call a
generative model.

Freshness follows each MIC's latest completed exchange session. Weekends and
holidays do not cause refetches when that session is already cached. Corrections
periodically revisit the bounded recent window; a newly observed split/dividend
requires full retained-history reconciliation for that symbol only. Failed
reconciliation preserves good data, suppresses incoherent indicators and records
a ticker-specific error. Bad symbols do not prevent good symbols being written.

`refresh_market` returns its independent outcome, exit code (0 successful, 2
partially degraded), provider/HTTP counts, failed identities and changed paths.
It writes ordinary OHLCV caches, `latest.csv` and one compact `features.csv`, with
atomic, byte-idempotent writes. It does not write technical series, alerts,
research facts, ledgers or publication snapshots. Features use adjusted prices:
1/5-session changes, Wilder RSI14 and SMA200 when enough observations exist.

Valuation repricing is pure decimal arithmetic. Weighted fair value is the sum
of scenario fair values times their percentage probabilities; implied return is
100 times weighted fair value/current price minus one. Confidence shrinks that
return toward zero: low 0.4, medium 0.7, high 1.0. Minimum rating confidence is
medium. Initial adjusted-return thresholds are strong Buy >=40%, Buy >=20%,
Sell <=-10%, strong Sell <=-25%; Buys also require configurable positive base
returns (initially 10%/20% for Buy/strong Buy), and strong Buy requires high
confidence. These are research opinions with no holdings or account input. All
return and confidence thresholds are configurable.

Expired/unsupported research, insufficient confidence, stale or wrong-currency
prices and splits after assessment remain Unrated. Fresh prices never alter
assessed fair values, research dates or expiry. Post-assessment splits require a
research refresh rather than silently repricing assumptions stated per old share.

All market scenarios at this milestone are mocked/local checks. Live provider
smoke and independently scheduled operation belong to M7/M9. Evidence and exact
commits/CI are tracked in PLAN.md.


Local gates passed: 22 focused tests, all 648 unit/integration tests, Ruff
check/format, MyPy for 66 source files, and strict legacy data validations against
unchanged active data. No live Yahoo call was made.

The user's updated daily time is 13:00 `America/New_York`, recorded in the
`[schedule]` section of `research.ini`. M7 must use the timezone-aware GitHub
schedule `cron: "0 13 * * *"`, `timezone: "America/New_York"`; this replaces the
old time while preserving its migration freeze. GitHub's official
[workflow schedule syntax](https://docs.github.com/en/actions/reference/workflows-and-actions/workflow-syntax#onschedule)
supports this IANA timezone and daylight-saving behavior. It is recorded intent
until the new research-only workflows are deployed, not an active legacy run.
